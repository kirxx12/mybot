# Проект: Telegram бот для подготовки учеников к ЕГЭ по математике и информатике

Этот проект представляет собой Telegram бота, разработанного на Python с использованием библиотеки aiogram, который помогает моим ученикам подготовиться к ЕГЭ по математике и информатике.  Бот предоставляет случайные задания из базы данных и проверяет ответы пользователей.

## Ключевые особенности:

* **Асинхронная архитектура:** Использование `aiogram` обеспечивает высокую производительность и отзывчивость бота.
* **FSM (Finite State Machine):**  Реализована машина состояний для управления диалогом с пользователем.
* **Интерактивные кнопки:**  Удобная навигация с помощью inline-кнопок.
* **База данных SQLite:**  Хранение заданий и информации о пользователях в базе данных SQLite.
* **Обработка ошибок:**  Предусмотрена обработка ошибок, таких как отсутствие базы данных.
* **Разделение по предметам:**  Отдельные базы данных и функционал для математики и информатики.

## Используемые библиотеки:

* `aiogram`:  Асинхронный фреймворк для создания Telegram ботов.
* `aiogram.contrib.fsm_storage.memory`:  Для хранения состояний FSM в памяти.
* `sqlite3`:  Для работы с базой данных SQLite.

## Функции:

* **`start_with_rep_bot(message)`:** Обработчик команды `/start`.
* **`delete_table_for_user(message)`:** Обработчик команды `/delete` (удаляет базы данных пользователя).
* **`help_for_rep_bot(message)`:**  Обработчик команды `/help`.
* **`start_with_math(call)`:**  Создает базу данных для математики.
* **`start_with_info(call)`:** Создает базу данных для информатики.
* **`get_task_info(call, state)`:**  Выдает случайное задание по информатике.
* **`check_answer_info_random_task(message, state)`:** Проверяет ответ на задание по информатике.
* **`get_task_math(call, state)`:** Выдает случайное задание по математике.
* **`check_answer_math_random_task(message, state)`:** Проверяет ответ на задание по математике.
* **`main_menu(call)`:** Отображает главное меню.
* **`math_menu(call)`:** Отображает меню математики.
* **`info_menu(call)`:** Отображает меню информатики.
